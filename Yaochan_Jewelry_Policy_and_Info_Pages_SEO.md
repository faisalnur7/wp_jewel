## SEO Notes for Implementation

- Set the **Page Title** and **Meta Description** for each page individually in your SEO plugin (Yoast SEO or Rank Math) — don't leave them as the default "Yaochan Jewelry" for every page.
- Use only one **H1** per page (the headline shown above); use H2/H3 for the subheadings within each page.
- Link between pages naturally where relevant — for example, link from "About Us" to "Our Stories," and from "Return Policy" to "Contact Us."
- Add descriptive alt text to every image (e.g., "gold-plated bohemian bracelet handmade in China factory") rather than leaving alt text blank — this helps with Google Image search traffic.
- Once live, submit your XML sitemap to Google Search Console so these pages get indexed.
